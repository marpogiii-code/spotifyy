# Spotifyy - Music Streaming Platform

A fully functional Spotify-like music streaming platform built with Next.js, featuring user authentication, real audio playback, playlists, search, and a responsive dark UI.

## Features

- **User Accounts** - Register, login, and manage your profile with secure JWT authentication
- **Music Streaming** - Real audio playback with play/pause, skip, shuffle, repeat, and volume controls
- **Playlists** - Browse curated playlists and create your own custom playlists
- **Search** - Search songs, artists, and playlists with genre browsing
- **Library** - Save your liked songs and manage your personal music collection
- **Responsive Player** - Full-featured music player with progress bar, queue management, and controls
- **Modern UI** - Pixel-perfect Spotify-inspired dark theme with smooth transitions

## Tech Stack

- **Next.js 14** - React framework with App Router
- **TypeScript** - Type-safe development
- **Tailwind CSS** - Utility-first styling
- **Zustand** - Lightweight state management
- **jose** - JWT authentication
- **bcryptjs** - Password hashing
- **Lucide React** - Beautiful icons

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

## Usage

1. **Sign Up** - Create an account with email and password
2. **Browse** - Explore playlists and discover music on the home page
3. **Search** - Find songs, artists, or playlists using the search bar
4. **Play** - Click any song to start streaming, use the player controls at the bottom
5. **Like** - Heart songs to save them to your Liked Songs
6. **Playlists** - Create custom playlists and add songs to them
